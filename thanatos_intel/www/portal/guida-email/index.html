Outlook (desktop)

  1. Outlook → File → Aggiungi account, inserisci l'indirizzo e scegli configurazione manuale / IMAP.
  2. Compila i server in arrivo/uscita con i parametri sopra.
  3. Password = la app-password. Spunta "Il server in uscita richiede l'autenticazione".
  4. Concludi: Outlook verifica e l'account è pronto.

iPhone / iPad

  1. Impostazioni → Mail → Account → Aggiungi account → Altro → Aggiungi account Mail.
  2. Nome, indirizzo e app-password; tipo IMAP.
  3. Server in arrivo e in uscita: mailmx.onekeyco.com.

Android

  1. App Email → Aggiungi account → Altro / IMAP.
  2. Indirizzo + app-password; in arrivo 993 SSL, in uscita 587 STARTTLS.

Webmail (senza configurare nulla)

Dal browser: webmail.thanatos.agency — accedi con la tua casella, oppure con "Accedi con MMOS ID" (single sign-on, per le caselle abilitate).

Se la posta smette di funzionare dopo un cambio password: chiedi all'amministratore una nuova app-password e aggiornala nel programma. Non serve toccare la password principale.
